# Функции расстояния и метрические методы: вопросы 22–24

Код к презентации. Скрипт `distances_demo.py` воспроизводит все числа и графики со слайдов.

```bash
pip install numpy matplotlib scikit-learn
python distances_demo.py
```

Числа печатаются в консоль (их копия лежит в `results.txt`), графики сохраняются в папку `figures/`.

## Что показывает код

**1. DTW (вопрос 22).** Своя реализация динамическим программированием, с полосой Сакоэ–Чибы и нормировкой на длину пути.

| Сравнение | Евклид после растяжения | DTW / длина пути |
|---|---|---|
| A (40 точек) и B (70 точек, та же форма, сдвиг) | 1.59 | 0.15 |
| A и C (55 точек, другая форма) | 1.62 | 0.51 |

Евклидово расстояние после равномерного растяжения почти не различает «тот же импульс, но позже» и «совсем другую форму». DTW различает их в 3,4 раза. Кроме того, DTW((1,2,3), (1,1,2,2,3)) = 0, то есть DTW не метрика.

**2. Махаланобис (вопрос 23).** Для точек x = (2, 1) и y = (0, 0):

| Ковариационная матрица | d_M | Нормированный евклид | Евклид |
|---|---|---|---|
| ρ = 0.8 | 1.054 | 1.414 | 2.236 |
| ρ = 0, σ² = (4, 1) | 1.414 | 1.414 | 2.236 |
| ρ = 0, σ² = 1 (Σ = I) | 2.236 | 2.236 | 2.236 |

При нулевой корреляции d_M совпадает с нормированным евклидовым расстоянием, при Σ = I совпадает с евклидовым.

**3. Линейная регрессия и KNN (вопрос 24).**

| Задача | MSE линейной регрессии | MSE KNN |
|---|---|---|
| Линейная зависимость, экстраполяция x ∈ [10, 15] | 0.33 | 34.87 |
| y = sin x внутри диапазона (K = 10 по кросс-валидации) | 0.441 | 0.005 |

KNN не выходит за пределы обучающих значений y (максимум прогноза 20.88 при максимуме y в обучении 22.13), поэтому не экстраполирует. На нелинейной зависимости KNN в 90 раз точнее.
